## 막힌 점 (2-B)
- `/docs`에서 `Failed to fetch` → 서버가 꺼져 있었음(8000번 포트 응답 없음). 원인: `.env`의 `USD_KRW=` 값이 비어 `float('')`에서 `ValueError`로 시작 실패
  → `os.getenv("USD_KRW", "1400")`의 기본값은 변수가 **없을 때만** 쓰임. `USD_KRW=`처럼 빈 값이 있으면 `''`이 들어옴 → `USD_KRW=1400`으로 고치고 서버 재시작
  → `Failed to fetch`(숫자 없음) = 연결 자체가 안 됨. 서버 터미널의 빨간 Traceback 마지막 줄부터 볼 것

## 막힌 점 (Day 3)
- `stream_test.py` 실행 → `HTTP Error 404` → `main.py`에 `/ask/stream` 코드를 안 넣고 테스트 스크립트만 만들었음. `/openapi.json`(또는 `/docs`)의 경로 목록에 없으면 404
- 코드 넣고 `docker compose up -d --build` 직후 바로 실행 → `RemoteDisconnected: Remote end closed connection without response` → compose의 `Started`는 컨테이너가 켜졌다는 뜻이지 서버 준비 완료가 아님. `docker compose logs api`에 `Application startup complete.`가 보인 뒤 실행하니 정상. (6주차 readiness probe + `/health`로 해결하는 문제)
