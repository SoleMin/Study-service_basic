# FastAPI 기본: 엔드포인트, Pydantic, /docs (2주차)

## 내 정리

### Q. FastAPI란 무엇인가? uvicorn은 무슨 역할인가?

- **FastAPI**: "어떤 주소로 요청이 오면 어떤 함수를 실행할지"를 정하는 프레임워크, 자체로는 요청을 받을 수 없고 다른 프레임워크와 연동해야함
- **uvicorn**: FastAPI에 받은 요청을 넘겨주는 서버 프로그램

### Q. 엔드포인트란 무엇인가? GET과 POST는 무엇이 다른가?

- **엔드포인트**: 2주차에 사용한 `/health`, `/echo`, `/chat` 같은 주소 하나 + 방식하나(메소드)
- **POST**: 요청과 함께 데이터를 보냄 (`/echo`, `/chat`)
- **GET**: 데이터를 가져오기만 함 (`/health`)

### Q. Pydantic 모델이란 무엇인가? 422 에러는 언제 나왔나?

- **Pydantic**: 응답 요청과 모양을 스키마 형태로 제한하기 위해 사용함, 만약 이 형태,값의 타입들이 일치 하지않으면 되돌려 보내기 위해 사용됨

### Q. /docs란 무엇이고 왜 쓰나?

fastAPI를 통해 만들어진 테스트 화면, POST와 같은 기능의 테스트를 위해 사용할 수 있음

## Claude 피드백

- **FastAPI (수정)**: "다른 프레임워크와 연동"보다는 "**서버(uvicorn)가 있어야 동작**"이 정확해요. FastAPI는 주소와 함수를 연결하는 규칙(앱)이고, 실제로 포트를 열고 HTTP 요청을 받는 건 ASGI 서버인 uvicorn이에요. `uvicorn app.main:app`은 "app 폴더의 main.py 안에 있는 `app` 객체를 서버로 띄워라"라는 뜻이에요.
- **엔드포인트, GET/POST**: 정확해요. 보태면 GET도 `?q=값` 같은 쿼리로 작은 값은 보낼 수 있고, POST는 JSON 본문(body)으로 큰 데이터를 보내요.
- **Pydantic (보완)**: "요청과 응답의 모양(스키마)을 정의하고, 들어온 값을 검사하고 타입을 변환"해요. 422 질문 답이 비어 있어요. 422는 요청 body가 모델과 안 맞을 때 FastAPI가 **함수를 실행하기도 전에** 자동으로 돌려보내는 에러예요(예: `/echo`에 `message` 필드를 빼거나 숫자 대신 글자를 넣었을 때). 실제로 /docs에서 일부러 필드를 지워 보고 결과를 적으면 좋아요.
- **/docs**: 맞아요. 코드의 엔드포인트와 Pydantic 모델을 보고 **자동으로 만들어지는** Swagger UI예요. 그래서 문서를 따로 안 써도 항상 코드와 일치해요. 화면 자체는 인터넷(CDN)에서 받아 오기 때문에, 처음에 화면이 비어 보였던 것도 "내가 막힌 점"에 적을 만해요.
