# Study-service_basic

5명이 7주 동안 Docker, FastAPI, RAG(LangChain), Kubernetes를 익혀서, 마지막 주에 **"k8s 위에 배포된 RAG API"**를 팀으로 완성하는 스터디 저장소예요. 7주 동안 함께 쓴 팀 위키(`team/wiki/`)가 그 RAG API의 문서 데이터셋이 되고, 데모 주제는 "우리 팀 위키에 질문하기"예요.

자세한 주차별 계획과 규칙은 [docs/스터디_계획.md](docs/스터디_계획.md)에 있어요.

## 로드맵

| 주차 | 주제 | 개인 결과물 |
| --- | --- | --- |
| 0 | 사전 준비 | Docker, Python 3.11, Git, kubectl, kind 설치 |
| 1 | Docker 기초 | 내 Python 앱을 이미지로 빌드해 실행 |
| 2 | FastAPI + docker compose | LLM을 호출하는 FastAPI 서버 + Redis 캐시 |
| 3 | RAG 기초 (LangChain) | 팀 위키로 답하는 RAG, 팀 평가 기준 고정 |
| 4 | RAG 고도화 + API화 | 하이브리드 검색 또는 리랭커, FastAPI `/ask` |
| 5 | Kubernetes 기초 | kind 클러스터에 Deployment + Service 배포 |
| 6 | RAG 앱 k8s 배포 | ConfigMap, Secret, PVC, 재적재 Job |
| 7 | 팀 프로젝트 통합 | 데모데이와 회고 |

## 폴더 구조

```
Study-service_basic/
├── docs/
│   └── 스터디_계획.md          주차별 상세 계획, 규칙, 평가 기준
├── members/                    개인 과제 (한 사람당 폴더 하나)
│   ├── _template/              새 멤버는 이 폴더를 복사해서 시작
│   └── <이름>/
│       ├── README.md           내 진행 현황
│       ├── week1/ ... week7/   주차별 실습 코드
│       └── wiki/
│           ├── raw/            실습 메모, 에러 로그, 참고 링크
│           └── pages/          개념 페이지 (팀 위키로 올릴 후보)
├── team/
│   ├── wiki/                   팀 지식 베이스 = 팀 프로젝트의 RAG 문서
│   ├── eval/                   질문셋과 평가 스크립트 (3주차)
│   ├── app/                    팀 프로젝트 코드 (4주차~)
│   └── k8s/                    k8s 매니페스트 (6주차~)
├── notes/                      단체 세션 기록 (기록자 담당)
├── .github/
│   └── pull_request_template.md
├── .env.example                API 키 이름 목록 (값은 비움)
├── .gitignore
└── CONTRIBUTING.md             브랜치, 커밋, PR 방법
```

## 시작하기

```bash
git clone https://github.com/SoleMin/Study-service_basic.git
cd Study-service_basic

# 내 폴더 만들기 (이름은 영문 소문자)
cp -r members/_template members/<이름>

# API 키 설정 (.env는 Git에 올라가지 않아요)
cp .env.example .env
```

그다음 `members/<이름>/README.md`에 이름을 적고, [CONTRIBUTING.md](CONTRIBUTING.md) 순서대로 첫 PR을 올려요.

## 규칙

- 개인 과제는 **단체 세션 전날까지 PR**로 제출해요. 다 못 해도 올리고, 못 한 것은 PR 설명에 적어요.
- 바이브 코딩은 자유롭게 쓰되, PR 설명에 **"왜 이렇게 동작하는지" 3줄**을 꼭 써요.
- API 키는 `.env`(로컬)와 k8s Secret(6주차)에만 둬요. 저장소에는 `.env.example`만 올려요.
- LLM API 계정에는 월 사용 한도를 걸어 둬요.
- 임베딩은 로컬 모델 `BAAI/bge-m3`을 팀 공통으로 써요.
- 팀 위키(`team/wiki/`)에는 **실습으로 직접 확인했고, 출처가 있고, 리뷰어 1명이 승인한** 페이지만 올려요.

## 팀 프로젝트 (4주차에 역할 분담)

팀 위키에 질문하면 출처와 함께 답하는 RAG API를 Kubernetes에 배포해요.

| 모듈 | 담당 | 내용 |
| --- | --- | --- |
| 데이터 파이프라인 |  | 위키 로드, 청킹(ID 부여), 임베딩, 벡터 DB 적재, 재적재 Job |
| 검색 (리트리버) |  | 벡터 검색, 하이브리드 또는 리랭커 |
| 생성 + 평가 |  | 생성 체인, 출처 반환, 질문셋과 `evaluate.py`, 개선 전/후 표 |
| API 서버 |  | FastAPI `/ask`, `/health`, 요청 로그 |
| 인프라 |  | Dockerfile, k8s YAML (Deployment, Service, ConfigMap, Secret, PVC, Job) |

**완료 기준**: 클러스터에 배포된 API가 팀 질문셋 25개에 출처와 함께 답하고, Pod를 하나 지워도 서비스가 계속 동작하며, 이 README에 기준선 대비 점수 표가 있으면 통과예요.
