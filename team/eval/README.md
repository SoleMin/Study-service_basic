# 팀 평가 기준 (3주차에 만들어요)

- `questions.jsonl`: 질문과 정답 위키 페이지(또는 청크 ID). 3주차 20개, 6주차에 k8s 질문 5개 추가
- `evaluate.py`: 리트리버를 넣으면 Recall@5, MRR@5, 질문당 평균 응답 시간을 출력. 3주차에 한 명이 만들고 나머지는 그대로 써요
- 기준선: 임베딩 `bge-m3`, `chunk_size=500`, `chunk_overlap=50`, 벡터 검색 `k=5`

자세한 내용은 [docs/스터디_계획.md](../../docs/스터디_계획.md)의 "팀 평가 기준"을 봐요.
